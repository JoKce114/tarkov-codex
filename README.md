# 塔科夫百科

逃离塔科夫的 Windows 本地资料查询工具。在首页同步游戏资料后，可离线查询已缓存内容。

## 功能

- **物品图鉴**：5498 件物品的价格、属性、兑换配方、制作配方
- **商人任务**：全部任务的目标、前置条件、奖励、地图点位、图文攻略
- **普通地图**提供 13 个地点的中文标注图，点击预览可查看高清原图。
- **交互地图**支持撤离点、出生点、容器、物资、危险区域和任务点的筛选，点击任务点可打开任务。
- **BOSS 图鉴**展示出现地图、刷新区域、生命值、装备与可能携带的物品，可直接查询关联地图和物品。
- **商人**：11 个商人的忠诚等级、在售物品、发布任务
- **兑换配方 / 藏身处制作 / 藏身处升级**：全部配方与建造材料
- **激活码**：当前有效的兑换码

支持 PVE / PVP / SEASON 三种游戏模式的数据切换，任务进度本地保存。

## 运行

需要 Python 3.10+（仅开发时需要，打包版不需要）。

```bash
pip install -r requirements.txt
python -m app.main
```

首次启动后在首页选择「全部同步」。游戏数据、地图与 BOSS、任务攻略和激活码也可单独同步。「设置 · 关于我们」提供软件更新检查和中文更新公告。

## 打包

```bash
python scripts/build_seed.py        # 生成出厂数据
python scripts/build_extra_seed.py  # 加入地图、攻略、激活码
python build/build.py               # 打包到 dist/
```

## 数据来源

| 内容 | 来源 |
|---|---|
| 物品、任务、商人、配方 | [tarkov.dev](https://tarkov.dev) 公开接口 |
| 地图、标记图标、BOSS 与物品 | [tarkov.dev](https://tarkov.dev) |
| 任务攻略、激活码 | [OPtarkov](https://www.optarkov.com) |
| 普通地图中文标注图 | [TarkovBox](https://www.tarkovbox.com/maps/download) |
| 地图绘制 | [RE3MR](https://re3mr.com) |

数据及地图绘制的署名归各来源。交互地图标记的许可随图标附带，游戏资料由应用同步到本地。

## 目录结构

```
app/            后端：数据加载、同步、接口
web/            前端：界面与交互
scripts/        数据抓取与打包辅助脚本
tests/          单元测试
build/          打包脚本
```

运行时会生成 `data/`（数据缓存）和 `logs/`（日志），均不纳入版本控制。
