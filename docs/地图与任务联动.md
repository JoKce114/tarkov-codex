# 地图与任务联动

## 玩家怎么用

从地图页选中任意地图，再点「交互地图」。13 张基础地图共用同一套筛选。夜间工厂、中心区 21+ 等变体在地图选择器中单列，使用各自的点位。准备做任务时，也可以从商人任务的具体目标点「地图定位」，直接打开对应地图。点位详情能打开任务抽屉，方便查看前置条件、所需物品、攻略和完成状态。

## 地图筛选

| 想查什么 | 筛选方式 |
| --- | --- |
| 从哪里进出 | 按 PMC、Scav、共享撤离点，以及转移点筛选 |
| 哪些角色会出生 | 按 PMC、Scav、Boss、游荡者等实际类型筛选 |
| 哪些物体能使用 | 勾选开关、固定机枪、上锁位置 |
| 去哪里搜容器 | 按保险箱、旅行包、抽屉、医疗包、工具箱等具体容器筛选 |
| 去哪里找某件物品 | 按物资类别筛选，或搜索物品名，查看可能刷新该物品的位置 |
| 哪些任务可以一起做 | 按任务目标、任务物品和当前模式的任务状态筛选 |
| 怎么辨认方向、避开危险区 | 勾选地名、地雷或狙击手等图层 |

每张图根据数据展示可用类型。点位密集时，点击地图上的分组可缩小查找范围。同一坐标存在多个目标时，可以分别查看。散落物资详情显示可能出现的候选物品。

地图有楼层资料时，可用「楼层」切换底图和点位。楼层选择与类别筛选可以叠加，比如在实验室单看某一层的容器。

## 实施与兼容

1. **地图数据**。在当前游戏模式下提取点位，按地图读取本地缓存。升级前只保存了地图名字的用户，可以在交互地图内单独同步点位。
2. **地图界面**。把筛选放在地图旁边，支持分组勾选、单类勾选、搜索、拖动、缩放和复位。继续提供原有高清图和系统看图入口。
3. **任务定位**。使用任务 ID 和目标序号关联位置。跨地图目标分别提供地图入口；只有数据源给出位置的目标才提供坐标定位。任务是否可接、是否已完成，沿用当前模式的任务进度。

## 验收场景

- 灯塔只勾选保险箱时可以逐个查看保险箱，恢复容器分组后显示其他容器。
- 搜索一个实际物品后可以查看其候选刷新点，同时查看附近的位置和撤离路线。
- 从任务目标跳到灯塔，打开对应标记并返回任务详情；完成或撤销任务后，地图反映新的状态。
- 切换模式后使用该模式的点位和任务进度。已缓存的底图和数据在断网后仍可打开。
- 从旧版升级后可以继续查看已经保存的高清图、任务进度和攻略。
- 逐张检查 13 张基础地图及其变体的底图与图层。实验室、迷宫和破冰船另外检查分块底图，夜间工厂与工厂分别核对任务来源。
