# 塔科夫百科桌面版升级规划

本轮版本为 0.3.0，实施日期为 2026 年 11 月 19 日。开发资料从空缓存重新同步，保留个人设置和任务进度。D 盘独立副本保留，用于核对旧版升级。

## 接口数量与返回内容

本地应用有 51 条 `/api/` 路由，供界面查询资料、保存进度和发起操作。外部游戏资料来自两家。tarkov.dev 的 JSON 服务每个模式有 7 个主数据集，其中 5 个另有中文翻译，三个模式合计 36 个数据地址。地图图片、图标、攻略页面和软件更新按用途单列，实际 HTTP 请求数会随缓存和资料数量变化。

| 外部接口或资源 | 返回内容 |
|---|---|
| tarkov.dev 物品、任务 | 物品分类、价格、属性、图片；任务前置、目标、地点与奖励 |
| tarkov.dev 地图 | 地图、撤离、出生、散落物资、容器、危险区域、首领及随从等记录；前端通过坐标和任务 ID 联动 |
| tarkov.dev 商人、藏身处、兑换、制作 | 商人等级和交易信息、设施升级条件、兑换材料与产物、制作时间与产物 |
| tarkov.dev 中文翻译 | 物品、任务、地图、商人和藏身处的中文名称与文本 |
| tarkov.dev 静态资源 | 底图、瓦片、43 个已接入的原版标记图标、物品及人物图片 |
| OPtarkov 三类入口 | 站点地图返回任务页地址与修改时间；任务详情返回攻略文字和配图地址；资讯接口返回激活码、起止日期和奖励 |
| 软件更新静态 GET | 版本、发布日期、中文公告、安装包地址、大小和 SHA-256；支持旧版清单和条件请求 |

实际修复顺序为图片缓存、资料源与攻略、地图筛选与任务联动、首页统一同步和 BOSS 图鉴、更新检查、中文安装升级及卸载验收。

## 1. 修复图片缓存

- 开发预览和正式程序共用目录初始化。物品图标、商人头像、任务缩略图和藏身处图片写入前建立父目录。写盘失败时仍可返回已经下载并验证的图片，日志保留失败原因。
- 用空缓存和现有缓存分别打开四类图片。检查首次请求能解码、二次命中缓存，以及断网重启后已缓存图片仍然可见。对真实缺图显示占位。
- 主要位置为 `app/assets.py`、`app/paths.py` 和开发预览启动入口。

## 2. 替换 TarkovBox 并补齐 OPtarkov 攻略

- 游戏资料使用 tarkov.dev 和 OPtarkov。把地图目录、详情、快速地图、地图图片入口逐项迁移到可用的新来源。保留任务跳地图、地图回任务、撤离点和钥匙详情的入口。需要替换的旧汉化图逐图登记覆盖情况。
- 关停 TarkovBox 地图、任务攻略和图片的在线请求，并更新出厂数据生成脚本。用全新安装和带旧缓存的升级安装各做一次请求记录，检查同步和打开详情时的实际访问目标。
- OPtarkov 按站点地图枚举任务 URL，取消编号上限和连续空页提前退出。沿用本地任务 ID，记录源页与任务的匹配关系。增量刷新已有攻略，把抓取失败、无攻略和未匹配分开统计。失败保留上一次成功的条目。
- 本次从 OPtarkov 重新抓取 505 页，其中 354 页关联到三模式共 368 个任务 ID，119 页无攻略正文，32 页尚未匹配。PVE 的攻略覆盖从 113/499 增至 359/499。
- 验收包括编号超过 519 的有效源页、旧攻略更新、单页失败重试和配图缓存。首页记录各项结果和最近成功时间。
- 主要位置为 `app/guides.py`、`app/maps.py`、`app/api.py`、`scripts/build_extra_seed.py` 和地图图片辅助脚本。

## 3. 全地图图标和首页同步

- 为全部基础地图、变体和可用楼层统一图标。按撤离阵营、出生点、容器类型、散落物品、任务物品和任务目标使用参考站映射。筛选项、搜索结果、地图标记共享同一映射，沿用现有任务 ID 和跳转逻辑。
- 首页提供「全部同步」和分项操作，覆盖游戏资料、BOSS 数据、地图点位与图标、OPtarkov 攻略和激活码。BOSS、地图和游戏资料复用同一份上游响应时合并请求。每项显示状态、最近成功时间和失败重试入口。
- 移除公共顶栏及地图、任务、激活码等内页的同步按钮、重试同步和隐式批量同步。缺资料时引导返回首页。浏览时按需读取单张图片，批量获取点位、图标和资料由首页发起。软件版本检查由设置单独管理。
- 逐图核对资源和筛选开关，抽检任务双向跳转及离线图标。遍历内页并记录请求，确认进入详情不会启动资料同步。重复点击首页同步只运行一份任务。
- 主要位置为 `web/index.html`、`web/app.js`、`web/atlas.js`、`app/api.py` 和 `app/sync.py`。

## 4. 首页 BOSS 图鉴

- 首页新增「BOSS 图鉴」。列表按照当前游戏模式展示肖像、名称和出现地图。详情展示中文介绍、刷新区域、已知刷新概率、随从、生命值、装备和可能掉落的物品。点击地图打开对应地图，点击掉落物打开现有物品详情。
- 从同一次地图同步中保留 BOSS 和物品关联。已在 PVE 的 Killa 记录中核实肖像、海报、生命值、装备和携带物品字段。地图资料里的 NPC 也包含普通单位，应按 BOSS 身份筛选。中文简介从已核实的资料整理，仅展示有依据的模式和概率。
- 用 Killa 贯通首页、详情、地图与物品，并验证普通单位过滤、多地图 BOSS、缺图和缺概率的展示。

## 5. 设置、关于我们和软件更新

- 设置提供「关于我们」，展示应用说明、当前版本、游戏资料来源、上次检查时间、自动检查开关和「检查更新」。程序运行时建议每 24 小时检查一次，启动时已到期则后台检查。手动操作立即反馈，多次点击合并请求。
- 客户端使用 HTTPS GET 读取固定的公开静态版本清单。清单包含版本、发布日期、中文公告、安装包下载地址、文件大小及 SHA-256。利用本地检查时间、ETag 或 Last-Modified、304 响应与失败退避减少流量。程序检查版本时无需访问 GitHub REST API。
- 发现更高版本时弹出中文公告，提供「下载更新」和「稍后」。同一版本自动提醒一次，用户仍可在「关于我们」重看。安装包通过完整性校验后由用户启动。离线或检查失败时仍可使用本地资料和当前版本。
- 软件更新使用公开发布仓库 `JoKce114/tarkov-codex-releases`。0.2.0 使用旧清单 `latest.json`，0.3.0 安装包同时生成 `update.json` 和兼容旧版的 `latest.json`。本轮交付本地安装包，发布操作独立进行。
- 验收覆盖相同版本、发现新版本、缓存未变、断网、重复点击、下载中断和校验失败。

## 6. 简体中文 Windows 安装、升级和卸载

- 保留现有 PyInstaller 应用目录，使用 Unicode NSIS 生成简体中文安装包 `TarkovCodex-0.3.0-Setup.exe`。首次安装支持选择目录，注册 Windows「已安装的应用」及中文卸载入口。
- 固定安装产品 ID，升级安装默认选中上一次安装目录。已有安装由安装器读取上次记录。旧便携版缺少安装记录时，允许用户选择原程序目录，识别并迁移原有进度、模式、设置和缓存。迁移成功后再次核验，避免失败重试覆盖新进度。
- 安装版将可写数据保存在当前用户的 `%LOCALAPPDATA%\TarkovCodex\data`。卸载保留设置、任务进度和游戏资料。首次安装和升级均使用与应用相同的版本号和中文界面。
- 当前打包脚本生成可分发目录。制作安装包前需要先生成新的 `app/seed`，并验证出厂资料来源。用含中文和空格的自选目录完成全新安装、覆盖升级、卸载和重装，核对安装路径、任务进度和设置。
